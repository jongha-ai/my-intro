## 기획

사장님에게 몰린 일 → AI 직원 출근 → 역할 분담 → 콘텐츠 제작 → 확인·승인 → 브랜드.
홈페이지(aiworkslab.kr)에 실제로 적힌 내용만 근거로 썼습니다: manager·researcher·content 역할 분담,
"대표님은 결과 확인과 최종 승인만", 블로그 원고 하나를 카드뉴스·SNS로 바꾸는 OSMU, 매거진·유튜브·인스타그램·스레드 채널, 조사·기획·제작·실행·검토 역할.
화면의 숫자(미처리 47건 등)와 업무 문구는 연출용 예시이며 실적 수치가 아닙니다.

## 제작 방식

기존 강의 오프닝(`opening/`)의 방식(HTML 모션그래픽 → Playwright 프레임 캡처 → ffmpeg)을 참고만 했고, 기존 소스는 수정하지 않았습니다.
세로형으로 새로 만들고, 되감기가 되는 GSAP 타임라인과 4개 병렬 렌더로 바꿨습니다. 음악(120BPM)과 효과음은 파이썬으로 직접 합성했고
효과음 109개는 화면 타임라인이 기록한 큐를 그대로 읽어 화면과 어긋나지 않습니다. 외부 유료 API는 쓰지 않았습니다.

## 다시 만들기

```bash
pip install numpy scipy && sudo apt-get install ffmpeg espeak-ng   # npm i -g playwright 도 필요
tools/make.sh            # 가이드 음성으로 전체 빌드 (약 4분)
tools/make.sh edge       # 자연스러운 음성으로 전체 빌드 (아래 참고)
```
문구는 `script.json`(자막·나레이션)과 `main.js`·`index.html`(화면)에서 고칩니다.

## 나레이션에 대해 (중요)

만든 환경에서는 신경망 한국어 음성에 접근할 수 없어서(음성 서비스·모델 저장소가 네트워크 정책으로 차단) 현재 영상의 나레이션은 오프라인 `espeak-ng` **가이드 음성**입니다.
기계음에 가까우므로 최종 게시용으로는 교체를 권합니다. 인터넷이 되는 PC에서 무료(API 키 불필요)인 Edge 음성으로 바꾸는 방법:

```bash
pip install edge-tts
python3 tools/make_narration.py --engine edge --voice ko-KR-SunHiNeural   # 또는 ko-KR-InJoonNeural(남성)
tools/make.sh edge
```
`edge` 경로는 만든 환경에서 실행해 볼 수 없어 **아직 검증하지 못했습니다.** 음성이 바뀌면 자막·음악 덕킹·효과음 큐가 새 길이에 맞춰 자동으로 다시 계산됩니다.
직접 녹음한 음성을 쓰려면 문장별 시작 시각에 맞춰 `audio/narration.wav`(44.1kHz 모노)와 `audio/narration_cues.json`을 같은 형식으로 만들면 됩니다.
