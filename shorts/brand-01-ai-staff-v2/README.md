## 기획

사장님에게 몰린 일 → AI 직원 출근 → 역할 분담 → 콘텐츠 제작 → 확인·승인 → 브랜드.
홈페이지(aiworkslab.kr)에 실제로 적힌 내용만 근거로 썼습니다: manager·researcher·content 역할 분담,
"대표님은 결과 확인과 최종 승인만", 블로그 원고 하나를 카드뉴스·SNS로 바꾸는 OSMU, 매거진·유튜브·인스타그램·스레드 채널, 조사·기획·제작·실행·검토 역할.
화면의 숫자(미처리 47건 등)와 업무 문구는 연출용 예시이며 실적 수치가 아닙니다.

## 제작 방식

기존 강의 오프닝(`opening/`)의 방식(HTML 모션그래픽 → Playwright 프레임 캡처 → ffmpeg)을 참고만 했고, 기존 소스는 수정하지 않았습니다.
세로형으로 새로 만들고, 되감기가 되는 GSAP 타임라인과 4개 병렬 렌더로 바꿨습니다. 음악(120BPM)과 효과음은 파이썬으로 직접 합성했고
효과음 109개는 화면 타임라인이 기록한 큐를 그대로 읽어 화면과 어긋나지 않습니다. 외부 유료 API는 쓰지 않았습니다.

## 다시 만들기

```bash
pip install numpy scipy && sudo apt-get install ffmpeg espeak-ng   # npm i -g playwright 도 필요
tools/make.sh            # AI Studio 음성(narration_map.json)으로 전체 빌드 (약 4분)
tools/make.sh espeak     # 오프라인 가이드 음성으로 빌드
```
문구는 `narration_map.json`(자막)과 `main.js`·`index.html`(화면)에서 고칩니다. 장면 길이는 `script.json`입니다.

## 나레이션

Google AI Studio에서 만든 한 파일(25.08초, 24kHz 모노)을 사용했습니다. 무음 구간으로 15개 덩어리로 나눠 7개 문장에 대응시키고(`narration_map.json`),
문장 안의 쉼은 원본 그대로 두고 문장 사이 간격과 장면 길이를 음성에 맞췄습니다. 자막·화면 동작·음악 덕킹·효과음 모두 실측 시각을 따릅니다.
문장 경계는 음성 인식 없이 무음 구간·음절 수·절별 합성 길이로 추정했습니다(두 방식이 같은 결과). 어긋나면 `narration_map.json`의 초 단위 값만 고치면 됩니다.

음성을 새로 만들었을 때: wav를 `audio/source/`에 넣고 `narration_map.json`의 구간(초)과 시작 시각을 고친 뒤 `tools/make.sh`.
오프라인 가이드 음성(`tools/make.sh espeak`)과 Edge 음성(`tools/make.sh edge`, 검증하지 못함) 경로도 남겨 두었습니다.
