# 강의 오프닝 모션그래픽 — 「AI로 시작하는 인생 2막」

70초 길이(1920×1080, 30fps)의 자기소개 오프닝 영상입니다.

| 파일 | 용도 |
|---|---|
| `dist/opening.mp4` | **완성 영상**. 강의 시작 때 이 파일을 바로 재생하면 됩니다. |
| `dist/opening_ppt_1080p.mp4` | **PPT 삽입용** (1080p, 약 14MB). 화질은 거의 같고 용량만 줄인 버전 |
| `dist/opening_ppt_720p.mp4` | PPT 삽입용 초경량 (720p, 약 9MB). 1080p 버전이 안 들어갈 때 사용 |
| `index.html` | 같은 영상을 브라우저에서 재생하는 원본(모션그래픽 코드). 문구를 고칠 때 사용합니다. |
| `assets/` | 사진, 폰트, 배경음악 |
| `tools/` | 영상 렌더링 / 음악 생성 / 폰트 생성 스크립트 |

## 장면 구성

| 시간 | 장면 | 화면 |
|---|---|---|
| 0~6초 | 프롤로그 | 어두운 강의실, 영사기 빛이 서서히 켜지고 스크린에 `저도 여러분과 같은 자리에서 시작했습니다.` |
| 6~14초 | 패션 사업 20년 | 웜톤 필름 질감. 원단 → 옷걸이 → 마네킹 순서로 클로즈업. `20년` 숫자가 1부터 올라감 |
| 14~20초 | 공인중개사 | 열쇠가 놓이는 순간 카메라가 살짝 흔들리고, 금색 선이 열쇠 → 계약서 → 건물을 연결 |
| 20~28초 | 택시 운전 | 비 내리는 밤 서울 도로, 지나가는 불빛. 마지막에 빛 속으로 줌인 |
| 28~33초 | 반전 | 화면 암전 후 딥네이비·코발트로 전환, 비트 시작. `처음 만난 AI.`가 타이핑됨 |
| 33~41초 | 배우고 실행하다 | 노트북 AI 대화 + `몰랐습니다 → 배웠습니다 → 써봤습니다 → 결과를 만들었습니다` |
| 41~51초 | 성과 폭발 | `3개월` / `400만 VIEW` / `첫 달 50만원` / `AI 로고송 → 기업 공식 채택` |
| 51~59초 | 지금의 나 | AIWorks 로고, `지금은 AIWorks를 운영합니다`, `AI 컨설턴트 · 50플러스 강사` |
| 59~65초 | 현재의 정체성 | AI들이 연결되는 네트워크 + `AI를 배우는 사람에서, AI를 부리는 사람으로.` |
| 65~70초 | 수강생에게 | `늦게 시작해도 괜찮습니다.` → `오늘은 여러분 차례입니다.` → 「AI로 시작하는 인생 2막」 |

## 브라우저에서 재생하기

`index.html`을 크롬으로 열고 화면을 클릭하면 음악과 함께 재생됩니다.

- `F` 전체화면 · `Space` 일시정지 · `R` 처음부터 · `←/→` 5초 이동

## 실제 사진·화면 캡처로 바꾸기

`assets` 폴더에 아래 이름으로 파일을 넣으면 자동으로 목업 대신 실제 이미지가 표시됩니다.

| 파일명 | 들어가는 곳 |
|---|---|
| `capture1.png` | 성과 ① 블로그 (국토교통부 우수 블로거 화면) |
| `capture2.png` | 성과 ② 유튜브 조회수 화면 |
| `capture3.png` | 성과 ③ 첫 수익 화면 |
| `capture4.png` | 성과 ④ AI 로고송 채택 화면 |
| `photo1.jpg` ~ `photo3.jpg` | "지금의 나" 장면의 프로필 사진 (현재 실제 사진 적용됨 — 같은 이름으로 덮어쓰면 교체) |
| `aiworks-logo.png` 외 2개 | AIWorks 로고 (현재 실제 로고 적용됨, 아래 참고) |

캡처는 가로 3:2 비율(예: 1200×800)이 가장 잘 맞습니다. 이미지를 넣은 뒤에는 아래 방법으로 MP4를 다시 만드세요.

## 문구 수정 후 MP4 다시 만들기

1. `index.html`에서 `SCENE` 주석 아래 글자를 수정합니다.
2. 새 글자가 들어갔다면 폰트를 다시 받습니다: `python3 tools/fetch_fonts.py`
3. 영상을 다시 렌더링합니다 (Node.js + Playwright, ffmpeg 필요):

```bash
cd opening
NODE_PATH=$(npm root -g) node tools/render.js                 # dist/opening.mp4 생성
NODE_PATH=$(npm root -g) node tools/render.js --stills 10,45  # 특정 시점 미리보기 이미지
```

배경음악은 `tools/make_audio.py`로 직접 합성한 음원이라 저작권 걱정 없이 사용할 수 있습니다.
다른 음악을 쓰려면 `assets/soundtrack.mp3`를 교체하세요(28.6초에 비트가 바뀌도록 편집하면 화면 전환과 맞습니다).

> 참고
> - AIWorks 로고: 받은 로고의 흰 배경을 투명하게 처리해 `aiworks-logo.png`(전체), `aiworks-mark.png`(심볼), `aiworks-word.png`(글자)로 나눠 씁니다. 심볼이 먼저 나오고 글자가 펼쳐지는 연출에 사용합니다.
> - 프로필 사진: `photo1.jpg`(팔짱), `photo2.jpg`(손짓), `photo3.jpg`(손 모음) 순서로 나옵니다.
> - 패션·부동산·택시 장면 이미지는 함께 주신 이미지입니다.
